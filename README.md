# tcp-json-calculator
使用 C++17 编写的 Linux TCP 网络计算器示例，采用客户端/服务端架构。客户端将两个整数和运算符组成请求，通过 JSON 序列化后发送；服务端接收请求、反序列化并执行加、减、乘、除、取模运算，再将计算结果和状态码序列化后返回。项目实现了基于报文长度和 CRLF 分隔符的自定义应用层协议，用于处理 TCP 字节流中的报文边界问题；服务端通过 fork() 为客户端连接创建子进程，支持多个客户端连接。适合学习 C++ Socket 编程、TCP 通信、JSON 序列化、自定义协议封包与解包，以及 Linux 进程并发处理。项目通过 Makefile 构建，依赖 JsonCpp。
